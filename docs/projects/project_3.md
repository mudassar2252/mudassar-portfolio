# 📘 Book Reading App

A modern and responsive web application built with **React** that allows users to explore, search, and manage their favorite books.

👉 [Visit the Live App](https://sprightly-donut-6eac8e.netlify.app)

## 🔗 GitHub Repository

👉 [View Source Code on GitHub](https://github.com/mudassar2252/book_reading_app)

---

## 🛠️ Technologies Used

- **React**
- **JavaScript**
- **HTML & CSS**
- **React Router**
- **Netlify (for deployment)**

---

## ✨ Key Features

- 📚 Browse a curated collection of books  
- 🔍 Search functionality to quickly find books  
- ❤️ Mark books as favorites  
- 📱 Fully responsive across devices  
- 🌐 Deployed on Netlify for fast performance

---


## 📌 Future Improvements

- 📝 Add notes or reviews on books  
- 🌍 API integration for real-time book data
